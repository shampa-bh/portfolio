# UK Household Financial Behaviour Analysis

## Objective
The aim of this project was to explore how income, spending, savings, and debt patterns differ across UK households.

## Data Source
The project used a **real household survey dataset published by the Bank of England**.

## Tools Used
- Microsoft Excel
- SQL

## What I Did
- Selected relevant variables from a much larger household survey dataset.
- Created a smaller working dataset focused on age, region, gender, housing, income, spending, savings, and debt.
- Used a codebook to understand coded survey responses.
- Converted coded values into readable categories using **XLOOKUP** and **VLOOKUP**.
- Cleaned and organised the dataset for analysis.
- Created PivotTables to compare household income and saving behaviour.
- Converted counts into percentages to make comparisons between income groups easier.
- Created a chart to visualise saving behaviour across selected income groups.
- Prepared a clean CSV version of the data for SQL analysis.
- Imported the dataset into a SQL database and practised filtering, grouping, counting, averages, sorting, and handling missing values.

## Key Findings
- Among the selected income groups, higher-income households were more likely to report that they had **saved more**.
- Around **10.5%** of households earning £17,500–£24,999 reported saving more, compared with approximately **25.3%** of households earning £75,000–£99,999.
- The proportion reporting that they had **saved less** fell from about **40.5%** in the £17,500–£24,999 group to approximately **28.2%** in the £75,000–£99,999 group.
- Across the three selected income groups, **saving about the same as usual** was one of the most common responses.
- The analysis suggests that higher-income households in the selected sample may have had greater capacity to maintain or increase their savings.

## Limitations / Next Steps
The dataset is based on survey responses, so some information is self-reported and may include missing or uncertain responses. The analysis also focused on selected variables and selected income groups, so the findings should not be interpreted as proving a causal relationship.
