# Analysing Museum Visitor Trends

## Objective
The aim of this project was to use visitor data to better understand demand, visitor behaviour, and satisfaction. The analysis focused on identifying patterns that could support data-driven decisions to improve the visitor experience and help maximise both museum impact and capacity.

## Data Source
The project used a fictional museum visitor dataset created with the help of AI for learning and portfolio purposes.

## Tools Used
- Microsoft Excel
- Excel Tables
- PivotTables
- Basic formulas
- Charts
- Data filtering and sorting

## What I Did
- Organised the visitor dataset into a structured Excel table.
- Used sorting and filtering to explore the data.
- Calculated basic summary statistics, including average visit duration and average visitor rating.
- Created PivotTables to analyse visitor numbers by exhibition.
- Compared weekday and weekend visitor numbers.
- Analysed average visitor ratings across different exhibitions.
- Created charts to make the findings easier to understand.
- Compared visitor attendance with visitor satisfaction to identify useful patterns.
- Interpreted the results and considered how the findings could support museum decision-making.

## Key Findings
- Music attracted the highest number of visitors, with 66 out of 200 visitor records.
- Natural World had the lowest number of visitors, with 37, but achieved the highest average rating of 4.22 out of 5.
- Art & Design attracted the second-highest number of visitors but had the lowest average rating of 3.73.
- Weekday attendance was much higher than weekend attendance, with 146 weekday visits compared with 54 weekend visits.
- Visitor popularity and visitor satisfaction did not always follow the same pattern.
